# ห้องเรียนออนไลน์: อ่านสรุปและฝึกทำข้อสอบ ๔ วิชา

ใช้ได้บน iPad, iPhone, Android และคอมพิวเตอร์ ไม่ต้องผ่าน App Store

## ไฟล์ในโฟลเดอร์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `content.js` | **เนื้อหาหนังสือและข้อสอบทั้งหมด** (ไฟล์เดียวที่ต้องแก้เป็นประจำ) |
| `index.html` | ตัวแอป |
| `sw.js` | ทำให้เปิดแอปได้ตอนไม่มีเน็ต |
| `manifest.webmanifest`, `icons/` | ชื่อและไอคอนตอนติดตั้งลงหน้าจอโฮม |

## อัปขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub (หรือใช้ repo เดิมแล้วลบไฟล์เก่าออก)
2. กด **Add file → Upload files** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในนี้ขึ้นไป (ต้องมีโฟลเดอร์ `icons` ด้วย)
3. ไปที่ **Settings → Pages** ตั้ง Source เป็น `Deploy from a branch`, branch `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
4. ถ้ามีโดเมนของตัวเอง ใส่ในช่อง **Custom domain** ในหน้าเดียวกัน
5. รอประมาณ 1–2 นาที แล้วเปิดลิงก์ที่ GitHub แสดง

## ติดตั้งบน iPad / iPhone

เปิดลิงก์ใน **Safari** → กดปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม**

## ติดตั้งบน Android

เปิดลิงก์ใน **Chrome** → กดเมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**

## เพิ่มหนังสือหรือข้อสอบ

เปิด `content.js` ด้านบนของไฟล์มีคำอธิบายวิธีเขียนอยู่ ให้ก๊อปบล็อกหนังสือเดิมแล้วแก้ข้อความ
- `id` ของหนังสือและข้อสอบต้องไม่ซ้ำกัน (ใช้ภาษาอังกฤษ ไม่มีช่องว่าง)
- `answer` ของข้อสอบเริ่มนับจาก 0
- `shuffle: true` จะสลับลำดับข้อและตัวเลือกทุกครั้งที่ทำ

อัปไฟล์ `content.js` ที่แก้แล้วขึ้น GitHub แทนไฟล์เดิม ผู้เรียนจะเห็นเนื้อหาใหม่ในครั้งถัดไปที่เปิดแอปขณะต่อเน็ต

## หมายเหตุ

- ความคืบหน้าการอ่านและผลสอบเก็บไว้ในเครื่องที่ใช้เท่านั้น (ไม่ส่งไปที่ไหน)
- ถ้าลบแอปหรือล้างข้อมูล Safari ผลสอบในเครื่องจะหายไปด้วย
